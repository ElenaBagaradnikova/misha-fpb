# Миша — FP Básica Electricidad y Electrónica

Персональный учебный тренажёр для подготовки к 1º Grado Básico de Electricidad y Electrónica.

Публичный сайт: https://mishafpb.netlify.app/

## Что уже работает

- 6 недель / 30 тем по IED, IT, Ciencias Aplicadas, CCSI и PIACI.
- Для каждой темы: теория на русском и испанском, испано-русский словарь, наглядная схема, видео/подборка, вопросы после видео, тренировочные задания и итоговый открытый ответ.
- Три режима нагрузки: «минимум», «нормально», «глубже».
- Автопроверка тестовых и числовых заданий.
- Родительская проверка открытых ответов с оценкой 0–2 и комментарием.
- Прогресс по предметам и история активности.
- Календарные сроки домашних блоков и отображение просроченных заданий.
- Экспорт и импорт локального прогресса в JSON.
- Supabase Auth, семейный кабинет, приглашение ученика и синхронизация прогресса между устройствами.

## Структура

- `index.html` — основной интерфейс.
- `css/styles.css` — стили сайта.
- `data/week1.js` … `data/week6.js` — учебное содержание по неделям.
- `data/cfg.js` — только публичная браузерная конфигурация Supabase.
- `js/app.js` — уроки, календарь, прогресс, тренажёр и локальное сохранение.
- `js/cloud.js` — аккаунты, семейный кабинет и облачная синхронизация.
- `build.mjs` — сборка статического сайта для Netlify.
- `netlify.toml` — настройки публикации.

## Локальные данные

До входа в облачный аккаунт ответы сохраняются в браузере под ключом `misha-fp-v3`. Этот ключ нельзя менять без миграции данных. При первом подключении ученика существующий локальный прогресс переносится в облачную запись, если серверная запись ещё пустая.

## Supabase backend

Проект `misha-fpb` содержит:

- `profiles` — профили пользователей;
- `households` — семейные кабинеты;
- `household_members` — связь родителя и ученика;
- `household_invites` — одноразовые коды приглашения;
- `student_states` — облачное состояние прогресса ученика;
- `parent_reviews` — родительские оценки и комментарии.

На пользовательских таблицах включён Row Level Security. Ученик изменяет только своё состояние; родитель получает доступ только к ученику в своём семейном кабинете и может сохранять проверки.

## Ключи

В браузере используется только Supabase publishable key — он предназначен для публичного клиентского кода и работает вместе с Auth и RLS. Secret/service_role key в сайт и репозиторий не добавляется.

## Сценарий подключения

1. Родитель регистрируется/входит и создаёт семейный кабинет.
2. Родитель получает одноразовый код приглашения.
3. Миша регистрируется/входит на своём устройстве и присоединяется по коду.
4. Его ответы и прогресс автоматически сохраняются в `student_states`.
5. Родитель открывает вкладку «Для родителя», загружает актуальный прогресс и сохраняет оценки/комментарии.

Если Supabase требует подтверждение email, после перехода по письму нужно просто вернуться на `mishafpb.netlify.app` и войти.

## Деплой

Репозиторий привязан к Netlify. Изменения в `main` автоматически публикуются на существующий сайт `mishafpb.netlify.app`.
