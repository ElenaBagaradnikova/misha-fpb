# Миша — FP Básica Electricidad y Electrónica

Персональный учебный тренажёр для подготовки к 1º Grado Básico de Electricidad y Electrónica.

Публичный сайт: https://mishafpb.netlify.app/

## Что уже работает

- 6 недель / 30 тем по IED, IT, Ciencias Aplicadas, CCSI и PIACI.
- Для каждой темы: теория на русском и испанском, испано-русский словарь, наглядная схема, видео/подборка, вопросы после видео, тренировочные задания и итоговый открытый ответ.
- Три режима нагрузки: «минимум», «нормально», «глубже».
- Автопроверка тестовых и числовых заданий.
- Родительская проверка открытых ответов с оценкой 0–2 и комментарием.
- Прогресс по предметам и история активности.
- Календарные сроки домашних блоков и отображение просроченных заданий.
- Экспорт и импорт локального прогресса в JSON.

## Структура

- `index.html` — основной интерфейс.
- `css/styles.css` — стили сайта.
- `data/week1.js` … `data/week6.js` — учебное содержание по неделям.
- `js/app.js` — отображение уроков, календарь, прогресс, тренажёр, родительский режим и локальное сохранение.
- `netlify.toml` — настройки публикации.

## Данные прогресса

Сейчас ответы сохраняются локально в браузере под ключом `misha-fp-v3`. Этот ключ нельзя менять без миграции данных: так существующий прогресс не пропадёт при обычных обновлениях сайта на том же домене.

Важно: пока прогресс одного браузера не синхронизируется автоматически с другим устройством. Для этого нужен backend.

## Родительский режим

PIN по умолчанию: `2468`. Сейчас это локальная защита интерфейса, а не полноценная серверная авторизация.

## Деплой

Репозиторий привязан к Netlify. Изменения в ветке `main` автоматически публикуются на существующий сайт `mishafpb.netlify.app`.

## Следующий технический этап

Подключить Supabase (или другой backend):

1. отдельные учётные записи ученика и родителя;
2. серверное сохранение ответов и событий;
3. автоматическая синхронизация между устройствами;
4. полноценный родительский дашборд с динамикой по датам, пропусками и проверками;
5. резервное хранение истории прогресса независимо от браузера.
