# Миша — FP Básica Electricidad y Electrónica

Персональный учебный тренажёр для подготовки к 1º Grado Básico de Electricidad y Electrónica.

Публичный сайт: https://mishafpb.netlify.app/

## Что уже работает

- 6 недель / 30 тем по IED, IT, Ciencias Aplicadas, CCSI и PIACI.
- Для каждой темы: теория на русском и испанском, испано-русский словарь, наглядная схема, видео/подборка, вопросы после видео, тренировочные задания и итоговый открытый ответ.
- Три режима нагрузки: «минимум», «нормально», «глубже».
- Автопроверка тестовых и числовых заданий.
- Родительская проверка открытых ответов с оценкой 0–2 и комментарием.
- Прогресс по предметам и история активности.
- Календарные сроки домашних блоков и отображение просроченных заданий.
- Экспорт и импорт локального прогресса в JSON.

## Структура

- `index.html` — основной интерфейс.
- `css/styles.css` — стили сайта.
- `data/week1.js` … `data/week6.js` — учебное содержание по неделям.
- `js/app.js` — отображение уроков, календарь, прогресс, тренажёр и локальное сохранение.
- `js/cloud.js` — клиентский слой облачной синхронизации.
- `build.mjs` — сборка Netlify и создание runtime-конфигурации из environment variables.
- `netlify.toml` — настройки публикации.

## Локальные данные

До входа в облачный аккаунт ответы сохраняются в браузере под ключом `misha-fp-v3`. Этот ключ нельзя менять без миграции данных: существующий прогресс должен сохраняться при обновлениях сайта на том же домене.

## Supabase backend

Создан проект `misha-fpb` и серверная схема:

- `profiles` — профили пользователей;
- `households` — семейные кабинеты;
- `household_members` — связь родителя и ученика;
- `household_invites` — одноразовые коды приглашения;
- `student_states` — облачное состояние прогресса ученика;
- `parent_reviews` — родительские оценки и комментарии.

На пользовательских таблицах включён Row Level Security. Родитель может читать данные связанного ученика и сохранять проверки, ученик — читать и изменять только своё состояние.

## Netlify runtime settings

Секретные ключи в репозиторий не добавляются. Сборка читает две переменные окружения Netlify:

- `CLOUD_ENDPOINT` — URL проекта Supabase;
- `CLOUD_PUBLIC` — только publishable browser token.

`build.mjs` формирует `dist/js/runtime.js`, который используется браузерным клиентом.

Никогда не добавлять в браузер или репозиторий secret/service_role key.

## Родительский режим

После активации облачного клиента родительский доступ должен определяться аккаунтом и членством в семейном кабинете. Старый PIN `2468` остаётся только резервным локальным режимом до полного включения cloud-клиента.

## Деплой

Репозиторий привязан к Netlify. Изменения в `main` автоматически публикуются на существующий сайт `mishafpb.netlify.app`.

## Осталось для включения синхронизации

1. загрузить готовую полную версию `js/cloud.js`;
2. задать `CLOUD_ENDPOINT` и `CLOUD_PUBLIC` в Netlify;
3. указать `mishafpb.netlify.app` как Site URL / Redirect URL в Supabase Authentication;
4. проверить создание родительского кабинета, приглашение Миши, двустороннюю синхронизацию и родительскую проверку.
