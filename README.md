# Миша — FP Básica Electricidad y Electrónica

Персональный учебный тренажёр для подготовки к 1º Grado Básico de Electricidad y Electrónica.

Публичный сайт: https://mishafpb.netlify.app/

## Структура

- `index.html` — разметка интерфейса.
- `css/styles.css` — стили.
- `data/lessons.js` — учебные темы, теория на русском и испанском, словарь, видео и вопросы.
- `js/app.js` — прогресс, сохранение ответов, родительский режим, экспорт/импорт.
- `assets/images/` — изображения к урокам.
- `assets/diagrams/` — схемы и иллюстрации.

## Данные прогресса

Пока ответы сохраняются локально в браузере под ключом `misha-fp-v3`. Этот ключ нельзя менять без миграции данных: так существующий прогресс не пропадёт при обновлении сайта на том же домене.

## Родительский режим

PIN по умолчанию: `2468`. Сейчас это локальная защита интерфейса, а не полноценная серверная авторизация.

## Деплой

Репозиторий привязан к Netlify. Изменения в `main` должны автоматически публиковаться на существующий сайт `mishafpb.netlify.app`.

## Следующий этап

Подключить серверное хранение (например, Supabase), отдельные аккаунты ученика/родителя и синхронизацию прогресса между устройствами.
